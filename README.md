# 📚 Student Attendance Management System – Low-Fidelity Wireframe

## ✨ Project Overview

This is a **Student Attendance Management System Low-Fidelity Wireframe** created using Figma. The system is designed to help students, teachers, and administrators manage and monitor attendance easily. The wireframe focuses on simple layouts, basic navigation, and clear user flow.

## 🎯 Objective

The main objective of this project is to design a simple and user-friendly attendance management system that helps students view their attendance, teachers mark attendance, and administrators monitor attendance reports.
